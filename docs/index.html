themeloom

A theme is a contract, not a palette.

Colour, type, shape, motion and an optional flourish — declared once as typed tokens, applied by flipping one attribute. No Tailwind, no build step, no framework.

Install

# the engine, a pack, and the picker
npm install @themeloom/core @themeloom/themes-classic @themeloom/picker

# or scaffold it
npx themeloom init
import { ThemeEngine } from '@themeloom/core';
import { classicThemes, classicCategories } from '@themeloom/themes-classic';
import '@themeloom/picker';
import '@themeloom/core/preset.css';
import '@themeloom/themes-classic/flourishes.css';

const engine = new ThemeEngine({
  themes: classicThemes,
  categories: classicCategories,
  persist: 'localStorage',
  storageKey: 'site-theme',
  default: 'minimalism',
});

engine.set('terminal');
engine.on('change', (event) => console.log(event.theme.id));
